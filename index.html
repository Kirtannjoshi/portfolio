Projects

Flagship applications and open-source software.

CultPop — Media Universe & Discovery Platform

Premium full-stack media logging & discovery platform unifying movies, iTunes soundtracks, books, and social culture feeds. Built with Next.js 15, TypeScript, Express, and MongoDB.

Tuner — High-Fidelity Global Radio Ecosystem

Radio streaming ecosystem across Android & Web unifying 40,000+ stations worldwide with low-latency audio routing, ExoPlayer engine, and Firebase infrastructure.

BITCHAT — Walkie-Talkie Instant Messenger

Minimalist browser communication tool inspired by walkie-talkie simplicity. Instantaneous text delivery with zero clutter, lightweight state, and clean UI.

Sutra — Next-Gen Cinematic Discovery Platform

Interactive media tracking platform with embedded trailers, dynamic community feeds, watched diary, and glassmorphic UI. Built with Next.js 14 and Tailwind.

Image Search Engine

Clean and simple image search engine built with HTML, CSS, and JavaScript. Instantly finds and displays high-res images using a fast, responsive grid UI.

BUMP — Anonymous Social Chat Platform

Privacy-first real-time messaging application designed for open social communication without exposing identity. Built with Node.js and real-time sockets.
